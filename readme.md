# Kiro NT

A late-90s workstation theme pack for [Kiro Crew](https://github.com/kirodotdev/KiroCrew),
sibling of [Kiro 98](https://github.com/jasonmimick-aws/kiro98-theme): silver bevels,
a solid navy title bar, a teal desktop behind the panels, pixel fonts, a Begin Logon
dialog when you switch it on, a server-console screensaver and a calm startup chime.

## Install

Settings → Display → Install theme, then give it this folder's path or this repo's
GitHub URL. Pick **Kiro NT**. On first activation Kiro Crew asks which experience parts
to turn on: **Sounds**, **Overlays** (desktop, logon dialog, screensaver) and
**Persona** (a calm sysadmin tone). Each one is optional.

Kiro 98 and Kiro NT install side by side; switch between them in the theme list.

## What's in the pack

| Part | File |
|---|---|
| Palette, light (classic silver) + dark (black wells) | `variables.json` |
| Bevels, solid navy title bar, square corners, scrollbars | `styles/overrides.css` |
| Pixelify Sans (UI), VT323 (code) | `styles/fonts/` |
| Navy-tile logo and favicon, workstation welcome image | `branding/` |
| Hourglass loader | `loader/hourglass.svg` |
| Teal desktop behind the panels | `overlays/desktop.html` |
| Begin Logon dialog, once on activation | `overlays/logon.html` |
| Server-console screensaver after 3 idle minutes | `overlays/screensaver.html` |
| Startup swell, notification ding, error bonk | `audio/` |
| Calm sysadmin tone (optional) | `persona.md` |

All art and sounds are original and generated by `.github/scripts/build_assets.py`.
A blue text-mode boot splash waits in `.github/art/splash.svg` until Kiro Crew accepts
`branding/splash.svg`.

## Limits

Theme packs can only restyle Kiro Crew's stable hooks. Other buttons, menus and dialogs
keep their stock shapes but pick up the palette and square corners.
